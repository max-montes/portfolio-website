Private single-user automation

New Grad Google Alert

A personal automation owned and operated by Max Montes Soza that searches Google Careers for early-career software engineering postings and emails matching job alerts from and to maxmontessoza@gmail.com.

How it works

The app uses the Gmail API scopes gmail.send and gmail.readonly. Send access delivers alerts. Read-only access is used only to search Sent mail for a unique alert marker so the automation can verify and deduplicate alerts. It does not read unrelated message contents.

OAuth client configuration and the refresh token are stored locally in macOS Keychain. Gmail message content is not retained, and data is transmitted only to Google APIs as necessary to provide the automation.
